# OpenRice Pay 報價計算機

單檔 HTML 銷售報價工具。打開 `index.html` 即可使用，無需安裝。

## 使用

- 直接用瀏覽器打開 `index.html`
- 或開 GitHub Pages（Settings → Pages → Deploy from branch `main` / root）
- 英文版：在網址加 `?lang=en`

## 功能

- 中／英切換
- 商家、Sales、每日信用卡 GMV、本地／海外卡比例
- 中小企／堂食／快餐方案比較
- OpenRice 統一費率 vs 現有供應商實際費率
- 匯出 PDF 報價單

最終費率以正式合約為準。
