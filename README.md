# OpenRice Pay 報價計算機

單檔 `index.html`，用瀏覽器打開即可，無需安裝。

**Repo:** https://github.com/fionatang3277/openrice-pay-calculator

## 使用

1. 下載 [`index.html`](./index.html) 用 Chrome / Safari 打開
2. 英文：在網址加 `?lang=en`
3. 開 GitHub Pages（公開網址）：
   - Settings → Pages
   - Source = Deploy from a branch
   - Branch = `main` / `/ (root)` → Save
   - 稍等後開：https://fionatang3277.github.io/openrice-pay-calculator/

## 功能

- 中／英切換
- 商家、Sales、每日 GMV、本地／海外卡比例
- 中小企、堂食、快餐方案
- OpenRice 統一費率 vs 現有供應商實際費率
- 匯出 PDF

Logo 由 `openrice-pay-quotation` repo raw 圖檔載入。最終費率以正式合約為準。
